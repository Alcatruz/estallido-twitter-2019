Este directorio es el sitio publicado con GitHub Pages.

Las paginas son HTML escrito a mano. Los datos que leen se generan con
`R/20_sitio.R` desde las tablas versionadas de `output/tablas` y `data`, de
modo que el sitio se reconstruye sin el corpus.

  estilo.css     tokens y estilos compartidos
  sitio.js       utilidades de Plotly y tablas
  datos/         datos.js (window.ES) y red.js (window.ESRED), generados
  figuras/       las dos laminas que no tienen sentido como grafico interactivo
